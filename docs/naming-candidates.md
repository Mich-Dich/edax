# Rift: Name Candidates

About 150 candidates per field, as search directions. **†** marks names I know to be used already by a programming language, a large software project or a well-known tool; unmarked names still need the full check (GitHub, package registries, domains, trademarks, search results for "<name> programming language").

Context for judging them: Rift is a C++-inspired **systems** language that is explicit, safe by default and built for performance, with its own build system and package manager. It is meant for engines, tools and embedded/aerospace software. The CLI would be `<name>c` (like `riftc`) and the files `.<x>s` / `.<x>h`.
